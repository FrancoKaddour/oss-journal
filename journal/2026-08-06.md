## [react-router#15382](https://github.com/remix-run/react-router/pull/15382) — streamed Suspense hydration

Second react-router PR this week, same subsystem area as #15377. With `v8_viteEnvironmentApi`, the dev-only critical CSS reset (`setCriticalCss(undefined)` on mount in `HydratedRouter`) lands as a synchronous update during the hydration commit, while Suspense boundaries below the root are still dehydrated — on React 18 this makes React discard their streamed server HTML and re-render them ("This Suspense boundary received an update before it finished hydrating"). Fix: wrap the reset in `React.startTransition`, exactly what the React error suggests and the reporter (@tehfreak) proposed and verified against the shipped bundle. Credited in the PR.

Honest caveat carried in the PR body: the new integration test can't demonstrate the bug on `main` (React 19 absorbs the update) — it's a regression test for the `v7` backport (React 18), offered explicitly. Couldn't run it locally either: Windows blocks the symlink the Playwright harness needs, and WSL's Ubuntu 26.04 is too new for the repo's pinned Playwright build. Typecheck, prettier and the monorepo build pass; the repo's CI runs the integration suite.

## [zag#3246](https://github.com/chakra-ui/zag/pull/3246) — Floating Panel stacking (closes #3242 + #3243)

One PR, two bugs, one component:

- **Stale stack on close (#3243):** panels joined the shared `panelStack` on open but only left it on machine *destroy*. Closing the topmost panel left it marked `data-topmost` while the remaining panel stayed `data-behind`. Fix: the `closed` state now removes the panel from the stack on entry; reopening re-adds it through the existing open-entry action.
- **Stack order never reached the positioner (#3242):** the stack index (`--z-index`) was written only to the content element, but each positioner is a sibling stacking context — a content z-index can never reorder panels relative to each other. Fix: apply the index to the positioner and consume it via `zIndex: "var(--z-index)"` in `getPositionerProps`.

Shipped with a new two-panel `stacking` example page and two e2e regression tests asserting `data-topmost` and computed positioner z-index. Red-green verified locally: both tests fail on `main`, pass with the fix (package rebuilt in each direction).
